# 📄 PDF Pro Editor

**Production-ready, client-side PDF manipulation tool** - No backend, no uploads, complete privacy.

## ✨ Features

✅ **Upload & Preview** - Drag-drop PDF files  
✅ **Page Reordering** - Drag pages to rearrange order  
✅ **Merge PDFs** - Combine multiple files  
✅ **Delete Pages** - Remove unwanted pages  
✅ **Headers/Footers** - Add text, page numbers, dates  
✅ **Export** - Download modified PDF  
✅ **Offline** - Works without internet

## 📱 Usage
1. Drag PDF files or click upload
2. Reorder pages by dragging thumbnails
3. Click **Merge All** or **Export PDF**
4. Download appears in your Downloads folder
